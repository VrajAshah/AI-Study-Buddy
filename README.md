# AI Study Buddy

An AI-powered document processing and study assistant built in Python. The project extracts text from PDF documents, analyzes their content, cleans and structures the extracted text, and prepares it for intelligent processing such as semantic search, summarization, and question answering.

## Features

- PDF document reading
- Document analysis
- Text cleaning and preprocessing
- Sentence-based text chunking
- Modular architecture
- Extensible pipeline for OCR, classification, and AI integration

## Installation

```bash
git clone https://github.com/VrajAshah/AI-Study-Buddy.git

cd AI-Study-Buddy

pip install -r requirements.txt
```

## Run

```bash
python main.py
```
